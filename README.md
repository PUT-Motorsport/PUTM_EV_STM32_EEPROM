# EEPROM Emulation Library for STM32

EEPROM emulation library for STM32, based on X-CUBE-EEPROM.

## Supported MCUs
* STM32G0
* STM32G4
* STM32L4
* STM32H5

## Project Configuration (CMake)
To set the target MCU for your project, simply edit `CMakeLists.txt` and change the `STM32G4` directory name to match your target MCU family (e.g., `STM32G0`, `STM32L4`, or `STM32H5`) in these two paths:
* In `EEPROM_LIBRARY_INC`: `${CMAKE_CURRENT_SOURCE_DIR}/X-CUBE-EEPROM/Porting/STM32G4`
* In `EEPROM_LIBRARY_SRC`: `${CMAKE_CURRENT_SOURCE_DIR}/X-CUBE-EEPROM/Porting/STM32G4/flash_interface.c`

## Library Configuration (`eeprom_emul_conf.h`)
The configuration file is located at `X-CUBE-EEPROM/Core/eeprom_emul_conf.h`. You need to adjust the following definitions according to your application and hardware:

* **`START_PAGE_ADDRESS`** – Start address of the first page in the Flash memory used for EEPROM emulation. It must be carefully matched to the memory layout of your specific STM32 chip.
* **`CYCLES_NUMBER`** – The number of 10,000-cycle multiples requested. A value of `1` (minimum) guarantees 10k cycles. If you want 100,000 cycles, set it to `10`. Higher values will automatically increase the number of allocated Flash pages.
* **`GUARD_PAGES_NUMBER`** – The number of guard pages used to prevent frequent page transfers. It must be a multiple of 2 (e.g., `0`, `2`, `4`...).
* **`CRC_POLYNOMIAL_LENGTH`** and **`CRC_POLYNOMIAL_VALUE`** – CRC algorithm settings. By default, it uses a 16-bit polynomial (`LL_CRC_POLYLENGTH_16B`) and a value of `0x8005U`.
* **`NB_OF_VARIABLES`** – The maximum number of unique variables (virtual addresses) you intend to store.

## Basic Workflow (C++ Wrapper)

The library provides a convenient, type-safe C++ wrapper located in `Inc/eeprom.hpp`. Below is the standard workflow for integrating it into your code:

### 1. Prerequisites
The library relies on the hardware CRC module to verify data integrity and requires the Flash prefetch buffer to be enabled:

**CRC Module:**
* **In STM32CubeMX:** Go to `Computing` -> `CRC` and check `Activated`.
* **In Code:** Ensure the CRC clock is enabled (this is typically handled by `MX_CRC_Init()` generated by CubeMX). If doing it manually:
  ```cpp
  __HAL_RCC_CRC_CLK_ENABLE();
  ```

**Flash Prefetch Buffer:**
* **In STM32CubeMX:** Go to `System Core` -> `RCC` -> `Parameter Settings` and set `Prefetch Buffer` to `Enable`.
* **In Code:** Ensure the prefetch buffer is enabled by calling:
  ```cpp
  __HAL_FLASH_PREFETCH_BUFFER_ENABLE();
  ```

* Include the C++ header:
  ```cpp
  #include "eeprom.hpp"
  ```
* Define an `enum class` with a `uint16_t` underlying type to map your variable addresses. The number of addresses used must not exceed `NB_OF_VARIABLES`.
  ```cpp
  enum class EepromAddress : uint16_t {
      VAR_TEMPERATURE = 0,
      VAR_CALIBRATION = 1
  };
  ```

### 2. Initialization
Create an instance of the `Eeprom` class. Before initializing the EEPROM, remember to unlock the Flash memory.
```cpp
/* Create Eeprom instance using your address enum type */
Eeprom<EepromAddress> my_eeprom;

/* Unlock Flash memory */
HAL_FLASH_Unlock();

/* Initialize EEPROM */
if (my_eeprom.init() != HAL_OK) {
    // Handle initialization error
}
```

### 3. Creating Variables
You can create variables bound to specific addresses. The wrapper supports trivially copyable types of sizes 1, 2, or 4 bytes (e.g., `uint8_t`, `uint16_t`, `uint32_t`, `float`).

You can create a variable with an initial value (which is automatically written if the variable doesn't exist yet):
```cpp
auto temp_var = my_eeprom.new_var<float>(EepromAddress::VAR_TEMPERATURE, 25.0f);
```
Or create it without an initial value (its state will rely on what is currently stored in EEPROM):
```cpp
auto cal_var = my_eeprom.new_var<uint32_t>(EepromAddress::VAR_CALIBRATION);
```

### 4. Reading and Writing Data
Use the variable objects to read and write data. The `read()` method returns a `std::optional`.

**Reading:**
```cpp
std::optional<float> current_temp = temp_var.read();
if (current_temp.has_value()) {
    // Successfully read data: current_temp.value()
} else {
    // No valid data exists or read error occurred
}
```

**Writing:**
```cpp
bool error = temp_var.write(26.5f);
if (error) {
    // Handle write error
}
```

**Erasing:**
You can also erase a specific variable from the EEPROM:
```cpp
bool error = temp_var.erase();
```
